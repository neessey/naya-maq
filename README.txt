NAYA — VERSION HTML UNIFIÉE (APERÇU IPHONE 13)

Fichiers :
- index.html : connexion
- dashboard.html : accueil / tableau de bord
- ventes.html : journal des ventes (page ajoutée pour compléter la navigation)
- interaction.html : assistante vocale
- alertes.html : centre des alertes (page ajoutée pour compléter la navigation)
- parametre.html : paramètres
- naya.css / naya.js : styles et comportements partagés
- logo1.png : logo officiel utilisé dans l'en-tête

Lancement :
1. Décompressez le dossier.
2. Ouvrez le dossier dans VS Code.
3. Lancez index.html avec Live Server.
4. Connectez-vous avec des valeurs de démonstration : le formulaire redirige vers dashboard.html.

À savoir :
- Toutes les pages de l'application utilisent la même coque iPhone 13 et la même navigation.
- Sur un vrai téléphone, le cadre disparaît et l'interface occupe l'écran.
- Les données, l'authentification, l'enregistrement vocal et les notifications restent à connecter à Firebase/backend.
- Les pages Ventes et Alertes ont été ajoutées car les menus d'origine les proposaient mais aucun fichier de page correspondant n'était fourni.
- Le numéro WhatsApp de démonstration déjà présent dans les paramètres doit être remplacé par le vrai numéro de support.
